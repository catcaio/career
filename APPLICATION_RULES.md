# APPLICATION_RULES.md — Regras de Candidatura

## Regras permanentes
1. Nunca enviar candidatura sem autorização explícita do Rafael (salvo regra futura criada por ele).
2. Nunca enviar informações falsas; nunca alterar fatos para inflar compatibilidade.
3. Sem spam: qualidade e aderência > quantidade.
4. Usar somente informações verdadeiras da base (career/).
5. Palavras-chave da vaga entram no currículo SOMENTE se verdadeiras para o perfil.

## Processo de cada vaga
1. VAGA ANALISADA (formato SOUL.md) → 2. Job fit → 3. Estratégia → 4. Currículo → 5. PDF (+ edição original) → 6. Revisão final → 7. Tracker.

## Nomenclatura de arquivos
`Rafa_NomeSobrenome_Curriculo_Empresa_Cargo.pdf` + versão editável junto.

## Estados do tracker
DISCOVERED → ANALYZING → READY_TO_APPLY → APPLIED → SCREENING → INTERVIEW → TECHNICAL → FINAL_STAGE → OFFER | REJECTED | WITHDRAWN | NO_RESPONSE

## Aprendizado contínuo
Registrar resultados (entrevista, rejeição, proposta, contato, feedback, pedido de alteração) e identificar padrões: cargos com mais entrevistas, versões que funcionam, competências valorizadas, lacunas recorrentes, setores com aderência. Diferenciar FATO / INFERÊNCIA / HIPÓTESE ao aprender.
