- `tracker.md` — Job Application Tracker (tabela com estados)

## Estados

## Regras
- Uma linha por vaga; evitar duplicação (checar por empresa+cargo+URL antes de registrar).
- Registrar: empresa, cargo, URL, data descoberta, data candidatura, status, fit estimado, currículo usado (versão), carta/mensagem, salário, localização, modalidade, contato, próxima ação + data, observações, resultado, motivo de rejeição.
